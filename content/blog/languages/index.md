## Критерии сравнения

Языки научного программирования оцениваются по трём параметрам:
1. Скорость выполнения
2. Ширина экосистемы
3. Порог входа

## Python

- **Скорость**: низкая (чистый Python), высокая (с NumPy/SciPy)
- **Экосистема**: огромная, всё есть
- **Порог входа**: низкий

Идеален для прототипирования, ML, Data Science.

## R

- **Скорость**: средняя, зависит от реализации
- **Экосистема**: огромная в статистике, слабая вне
- **Порог входа**: средний (необычный синтаксис)

Только для статистики и биоинформатики.

## Julia

- **Скорость**: высокая (близка к C)
- **Экосистема**: растущая, но незрелая
- **Порог входа**: средний

Для задач, где Python медленный, а писать на C++ не хочется.

## MATLAB

- **Скорость**: высокая (оптимизирован под матрицы)
- **Экосистема**: узкая, но глубокая (тулбоксы)
- **Порог входа**: средний + платно

Актуален в вузовской среде и оборонке.

Выбор диктуется задачей, а не модой.
