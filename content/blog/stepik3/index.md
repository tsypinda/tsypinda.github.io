## Текстовый редактор vim

![](image/рис1.png)

Для выхода из редактора vim сразу после открытия файла нужно нажать клавишу :, затем q и Enter, что переводит vim в командный режим и выполняет выход

![](image/рис2.png)

Различие между word и WORD: word состоит из букв, цифр и подчёркиваний, а WORD — из любых непробельных символов, поэтому нажатие w не может остановиться на точке, а для достижения конца строки требуется меньше нажатий W, чем w

![](image/рис3.png)

Для преобразования строки использованы команды: x2wwywPp — удаление слова "one", перемещение и вставка; d2wwywPp — аналогично с удалением двух слов; ddithree four four four five <Esc> — удаление строки и вставка новой; d2wwifour four <Esc> — удаление до "three" и вставка "four four"

![](image/рис4.png)

Команда :%s/Windows/Linux/ выполняет глобальную замену первого вхождения Windows на Linux в каждой строке файла (флаг g не используется, чтобы заменить только самое первое слово)

![](image/рис5.png)

В режиме Visual (открывается из нормального режима клавишей v) доступны команды перемещения, а также команды d (удалить) и y (скопировать)

## Скрипты на bash: основы

![](image/рис6.png)

Каждая оболочка bash имеет свою собственную историю команд, поэтому во вложенной оболочке будут доступны только команды, введённые непосредственно в ней (набор C)

![](image/рис7.png)

Скрипт сначала переходит в /home/bi/, затем создаёт файл file1.txt в этой директории, поэтому абсолютный путь к созданному файлу — /home/bi/file1.txt

![](image/рис8.png)

В bash имя переменной может состоять из букв, цифр и подчёркивания, но не может начинаться с цифры; допустимы variable_123, _variable, variable123, variable, VARIable

![](image/рис9.png)

Скрипт выводит строку с подстановкой первого и второго аргументов, при этом знак доллара перед $1 экранируется, чтобы напечатать литерал $1: echo "Arguments are: \$1=$1 \$2=$2". Например, при запуске ./script.sh one two на экране появится Arguments are: $1=one $2=two

## Скрипты на bash: ветвления и циклы

![](image/рис10.png)

Условия 5 -ge 5 (5 больше или равно 5) и -z "" (пустая строка) всегда истинны независимо от параметров скрипта и значений переменных

![](image/рис11.png)

При var=3 ни одно из условий не выполняется (3 не больше 5, не меньше 3, не равно 4), поэтому выводится "four". При var=5 условие -gt проверяет строгое неравенство (5 > 5 ложно), затем -lt 3 ложно, -eq 4 ложно, снова срабатывает else и выводится "four". Таким образом, оба раза будет напечатано "four"

![](image/рис12.png)

Скрипт анализирует первый аргумент $1: если 0 — "No students", если 1 — "1 student", если от 2 до 4 — "$1 students", иначе "A lot of students". В коде важно использовать условие -lt 5 для диапазона 2-4, потому что -lt означает "меньше"

![](image/рис13.png)

Цикл for перебирает три элемента: "a,", "b," и "c_d" (запятые входят в состав строк). Команда continue пропускает вывод "finish" для тех строк, которые лексикографически больше "c". Строка "c_d" больше "c", поэтому "finish" не выводится. Остальные две строки выводят и "start", и "finish". Итого "start" появится 5 раз, а "finish" — 4 раза

![](image/рис14.png)

Скрипт в бесконечном цикле читает имя и возраст. Если имя пустое или возраст равен 0, выводится "bye" и цикл прерывается. Иначе проверяется возраст: если <=16 — группа "child", если <=25 — "youth", иначе "adult". После вывода сообщения цикл повторяется

## Скрипты на bash: разное

![](image/рис15.png)

Команда let выполняет арифметические операции. Варианты let "a = a + b", let "a+=b", let "a=$a+$b" и let a=$a+$b корректно увеличивают a на значение b. Пробелы и кавычки важны: let a = a + b без кавычек вызовет ошибку, так как пробелы разделяют аргументы

![](image/рис16.png)

Обратные кавычки выполняют команду pwd, которая выводит текущий рабочий каталог. После cd /home/bi/ текущим становится /home/bi, поэтому echo выводит /home/bi

![](image/рис17.png)

Чтобы проверить код возврата программы, её нужно запустить отдельно, а затем проверить переменную $? (например, if [[ $? -eq 0 ]]). Нельзя использовать if `program`, потому что подстановка команды подставляет её вывод, а не код возврата

![](image/рис18.png)

В функции counter переменная c1 объявлена как local, поэтому её значение не сохраняется между вызовами — после десяти вызовов c1 остаётся пустой. Переменная c2 не локальная, она накапливает сумму: 2*(1+2+...+10)=110. Команда echo выводит "counters are and 110" (между are и and два пробела)

![](image/рис19.png)

Функция gcd реализует алгоритм Евклида через вычитание в цикле while. Пока M не равно N, из большего вычитается меньшее. После цикла выводится "GCD is <значение>". Основная программа читает пары чисел через read -r numbers, затем с помощью set -- $numbers разбивает строку на аргументы и вызывает gcd. При пустой строке выводится "bye" и выполнение прекращается

![](image/рис20.png)

Программа читает строки в цикле. Если введено "exit", выводится "bye" и цикл прерывается. Иначе пытается вычислить выражение через let r=$(($exp)). Если вычисление успешно, выводится результат, иначе выводится "error" и скрипт завершается

## Продвинутый поиск и редактирование

![](image/рис21.png)

Опция -iname игнорирует регистр, поэтому найдутся все файлы, начинающиеся с "star" в любом регистре. Опция -name учитывает регистр, поэтому найдёт только "Star_Wars.avi" и "STARS.txt" (оба начинаются с заглавной S)

![](image/рис22.png)

Опции -path и -name отличаются: -path сопоставляет весь путь, а -name только имя файла. Их замена иногда даёт одинаковый результат, например, когда файл находится в корне поиска. Утверждение "Если заменить -name на -path, результат поиска иногда может остаться таким же" верно

![](image/рис23.png)

Команда find с -mindepth 2 -maxdepth 3 ищет файлы на глубине 2 и 3 относительно /home/bi/. file1 находится на глубине 2 (/home/bi/dir1/file1), file2 — на глубине 3 (/home/bi/dir1/dir2/file2), file3 — на глубине 4 (/home/bi/dir1/dir2/dir3/file3). Поэтому будут найдены file1 и file2

![](image/рис24.png)

Во всех вариантах grep выводит одинаковое количество строк, потому что каждая строка файла содержит слово "word". Опции -A, -B, -C добавляют контекст, но так как в каждой строке есть искомое слово, то добавленные строки контекста — это те же самые строки, которые уже выводятся. В итоге все команды создадут файл results.txt одинакового размера

![](image/рис25.png)

Регулярное выражение "[xKXKL]?[uU]buntu$" ищет строки, заканчивающиеся на "buntu", перед которым может быть ноль или один символ из набора x, K, X, L

![](image/рис26.png)

Без опции -n sed печатает каждую строку по умолчанию, а команда p печатает строку ещё раз. Строки, соответствующие шаблону [a-z]* (любая строка, содержащая хотя бы одну строчную букву), будут выведены дважды

![](image/рис27.png)

Инструкция sed 's/ [A-Z][A-Z]\+ / abbreviation /g' input.txt > edited.txt заменяет последовательности из двух и более заглавных букв, окружённые пробелами, на слово abbreviation

## Строим графики в gnuplot

![](image/рис28.png)

Опция -p (--persist) при запуске gnuplot предотвращает закрытие окон с графиками после завершения работы программы

![](image/рис29.png)

При использовании set key autotitle columnhead и отсутствии заголовков в первой строке, gnuplot воспринимает первую строку как данные, а не как заголовок. Поэтому название ряда берётся из первого значения второго столбца (первая строка, второе поле). А всего точек будет нарисовано 9

![](image/рис30.png)

Команда set xtics создаёт пользовательские деления на оси X. Конкатенация строк выполняется с помощью точки

![](image/рис31.png)

Для отражения графика относительно горизонтальной плоскости функция изменена на -x**2-y**2 (вместо x**2+y**2). Обратное вращение достигается изменением приращения угла: zrot=(zrot+350)%360. Ускорение в два раза — уменьшением паузы с 0.2 до 0.1 секунды

## Разное

![](image/рис32.png)

Права rwxr-xr-- соответствуют числовому значению 764 (rwx=7, r-x=5, r--=4)

![](image/рис33.png)

Чтобы пользователь user из группы group мог создавать файлы в директории, нужно либо сменить владельца (sudo chown user dir или sudo chown user:group dir), либо добавить право записи для группы или всех с sudo: sudo chmod o+w dir или sudo chmod a+w dir

![](image/рис34.png)

Команда wc (word count) может подсчитать количество байт (опция -c), количество слов (-w) и количество символов (-m)

![](image/рис35.png)

Команда du -sh (или du -h -s) выводит суммарный размер текущей директории в "человеко-читаемом" формате (например, 2.4M)

![](image/рис36.png)

Самая короткая команда для создания трёх поддиректорий — mkdir dir{1..3}. Фигурные скобки в bash генерируют последовательность: dir1, dir2, dir3
